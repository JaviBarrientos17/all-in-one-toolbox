🚀 Cómo Usar

Versión Web

  1. El servidor de desarrollo ya está ejecutándose en http://localhost:1420
  2. Haz clic en el botón de arriba para abrir la aplicación en tu navegador
  3. Selecciona una categoría (Imágenes, PDF, Documentos)
  4. Elige una herramienta específica
  5. Arrastra archivos o haz clic para seleccionarlos
  6. Procesa y descarga los resultados

Versión Escritorio (Windows 10/11)

📝 Requisitos previos:
  • Rust instalado: https://rustup.rs/
  • Node.js 20+ instalado

🔧 Herramientas Disponibles

🖼️ Imágenes

  • Comprimir: Reduce el tamaño con configuración personalizable
  • Redimensionar: Cambia dimensiones especificando ancho y alto
  • Convertir: Convierte entre PNG, JPEG, WebP
  • Rotar: Rota 90°, 180° o 270°

📄 PDF

  • Fusionar: Combina múltiples PDFs en uno solo
  • Dividir: Separa todas las páginas en archivos individuales
  • Extraer: Extrae páginas específicas (ej: 1,3,5-7)
  • Rotar: Rota todas las páginas del PDF

📝 Documentos

  • TXT a PDF: Convierte archivos de texto a PDF
  • CSV a JSON: Convierte hojas CSV a formato JSON
  • JSON a CSV: Convierte arrays JSON a hojas CSV

📊 Historial

La aplicación guarda automáticamente un historial de todas tus operaciones. Puedes acceder al historial haciendo clic en el botón "📋 Historial" en la esquina superior derecha de la aplicación web.

🛡️ Privacidad y Seguridad

💚 Tu privacidad es nuestra prioridad
  • ✅ Procesamiento 100% local en tu navegador/ordenador
  • ✅ No se requiere conexión a internet (después de la carga inicial)
  • ✅ Sin servidores externos - tus archivos no se suben a ningún lado
  • ✅ Sin bases de datos ni almacenamiento en la nube
  • ✅ Sin seguimiento, analytics ni cookies
  • ✅ Sin registro de usuarios

📈 Reportes de Progreso

El proyecto genera reportes automáticos de progreso cada hora en la carpeta progress-reports/. Estos reportes incluyen:

  • Estadísticas del código
  • Funcionalidades implementadas
  • Estado de desarrollo
  • Próximos pasos

💡 Consejos y Trucos

  • Drag & Drop: Puedes arrastrar archivos directamente a la zona de carga
  • Múltiples archivos: La mayoría de herramientas soportan procesamiento por lotes
  • Configuración avanzada: En la compresión de imágenes, puedes ajustar calidad y dimensiones
  • Preview: Las imágenes se muestran con preview antes de procesar
  • Historial: Revisa tus operaciones anteriores en cualquier momento
