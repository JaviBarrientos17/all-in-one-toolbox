# Changelog

Todos los cambios notables del proyecto se documentan en este archivo.

## [1.0.0] - 2026-05-30

### ✨ Añadido

#### Funcionalidades Principales
- **Interfaz de usuario completa** con navegación por categorías
- **Procesamiento 100% local** sin necesidad de servidor backend
- **Interfaz responsive** optimizada para móvil, tablet y escritorio
- **Sistema de historial** que guarda todas las operaciones realizadas

#### Herramientas de Imagen
- Compresión con configuración avanzada (calidad, tamaño, dimensiones)
- Presets rápidos para compresión (Alta calidad, Equilibrada, Web, Máxima)
- Redimensionamiento con dimensiones personalizables
- Conversión entre formatos (PNG, JPEG, WebP)
- Rotación (90°, 180°, 270°)
- Marca de agua configurable (texto, tamaño, posición, opacidad)
- Preview de imágenes antes de procesar
- Drag & drop de archivos
- Eliminación individual de archivos seleccionados

#### Herramientas de PDF
- Fusionar múltiples PDFs en uno solo
- Dividir PDF en páginas individuales
- Extraer páginas específicas (ej: 1,3,5-7)
- Rotar todas las páginas
- Drag & drop de archivos

#### Herramientas de Documentos
- Convertir TXT a PDF con formato
- Convertir CSV a JSON
- Convertir JSON a CSV
- Drag & drop de archivos

#### Sistema de Reportes
- Generación automática de reportes HTML cada hora
- Reportes con estadísticas de código
- Estado de funcionalidades implementadas
- Próximas tareas planificadas

### 📚 Documentación
- README completo con instrucciones de uso
- Guía de usuario interactiva (HTML)
- Changelog
- Licencia MIT

### 🛠️ Infraestructura
- Configuración de Vite
- Integración de Tailwind CSS
- TypeScript estricto
- Scripts npm para desarrollo y construcción
- Sistema de reportes automáticos

### 🔒 Seguridad y Privacidad
- Todo el procesamiento se realiza en el navegador
- Sin envío de datos a servidores externos
- Sin almacenamiento en bases de datos remotas
- Sin tracking ni analytics
